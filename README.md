# 만나기 체크리스트 (부부 공유 웹앱)

출산가방 리스트와 출산 후 정책 신청 리스트를 아내·남편이 **실시간으로 같이 체크**하는 웹앱이에요.
폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

## 기능
- 두 개의 리스트: 🎒 출산가방, 📋 출산 후 신청 (2026년 기준으로 조사한 정책 항목 포함)
- 부부가 같이 정한 **비밀번호(숫자 4자리)** 로 로그인
- 항목 체크 / 추가 / 수정 / 삭제, 메모, 담당(아내·남편·같이), 기한, 바로가기 링크
- 누가 언제 체크했는지 표시, 🔔 최근 업데이트 목록과 안 읽은 알림 배지
- 아기 이름(태명)과 출산(예정)일을 넣으면 제목이 "○○ 만나기 체크리스트"로 바뀌고, 신청 항목의 권장 기한(D-day)이 자동 계산돼요
- 필터: 전체 / 남은 것 / 내 것 / 완료

## 파일 구성
| 파일 | 역할 |
|---|---|
| index.html, style.css, app.js | 앱 본체 |
| seed.js | 처음 만들 때 채워지는 기본 리스트 (고치고 싶으면 여기 또는 앱에서) |
| config.js | **Firebase 설정을 붙여넣는 파일** + 공용 로그인 이메일 |
| firestore.rules | 데이터베이스 보안 규칙 |
| manifest.json, icon-*.png | 홈 화면 추가용 |

> 아기 이름과 출산(예정)일은 코드에 넣지 않아요. 처음 로그인하면 나오는 **처음 설정** 화면이나 ⚙️ 설정에서 입력하면 Firebase에만 저장돼요. (저장소가 공개라서예요. RULES.md 참고)

## 설정 순서

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 접속 → 구글 계정으로 로그인
2. **프로젝트 추가** → 이름 입력 → Google 애널리틱스는 꺼도 돼요 → 만들기

### 2. 비밀번호 로그인 켜고 공용 계정 만들기
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭 → **이메일/비밀번호** → 사용 설정(첫 번째 스위치만) → 저장
3. **사용자** 탭 → **사용자 추가**
   - 이메일: `family@example.com` (config.js의 `LOGIN_EMAIL`과 같아야 해요. 실제 메일함이 아니어도 돼요)
   - 비밀번호: **`pin-` 뒤에 부부가 정한 숫자 4자리**를 붙여서 입력해요. 예) 비밀번호가 0000이면 `pin-0000`
   - 앱에서는 숫자 4자리만 입력하면 돼요. (Firebase는 6자 이상 비밀번호만 받아서 앞에 `pin-`을 붙여요)
4. **설정** 탭 → **사용자 작업**에서 **생성(가입) 허용**을 꺼요. 모르는 사람이 계정을 만들지 못하게요.
5. 익명 로그인을 예전에 켰다면 꺼도 돼요.

비밀번호를 바꾸려면 **사용자** 탭에서 계정을 삭제하고, 같은 이메일과 새 비밀번호로 다시 추가해요. 리스트 데이터는 그대로 남아요. ("비밀번호 재설정"은 메일을 보내는 기능이라 가짜 이메일에는 쓸 수 없어요.)

### 3. 데이터베이스(Firestore) 만들기
1. **빌드 → Firestore Database → 데이터베이스 만들기**
2. 위치는 **asia-northeast3 (서울)**, **프로덕션 모드**로 시작
3. **규칙** 탭 → 내용을 모두 지우고 `firestore.rules` 파일 내용을 붙여넣기 → **게시**

### 4. 앱 설정값 복사
1. 톱니바퀴 **프로젝트 설정 → 일반 → 내 앱**에서 웹 아이콘 `</>` 클릭
2. 앱 닉네임 입력 → 앱 등록 (Firebase 호스팅 체크는 안 해도 돼요)
3. 화면에 나오는 `firebaseConfig = { ... }` 값(apiKey, authDomain, projectId 등)을 `config.js`의 같은 이름 자리에 붙여넣고 저장

> ⚠️ 공개 저장소(GitHub Pages)에 올리기 전에 **RULES.md**를 읽어보세요. Firebase의 `apiKey`는 공개돼도 되는 값이에요. 실제 접근은 비밀번호와 보안 규칙으로 막아요.

### 5. GitHub Pages로 배포하기 (무료)
1. https://github.com 로그인 → 오른쪽 위 **＋ → New repository**
2. 이름 입력, **Public** 선택 → **Create repository**
3. 만들어진 화면에서 **uploading an existing file** 클릭 → 이 폴더 안의 파일과 폴더를 **전부** 끌어다 놓기 → **Commit changes**
4. 저장소 **Settings → Pages → Branch: main / (root)** → Save
5. 몇 분 뒤 `https://아이디.github.io/저장소이름/` 주소가 열려요.

내용을 고친 뒤에는 바뀐 파일만 같은 방법으로 다시 올리면 돼요. 자주 고칠 거라면 GitHub Desktop을 설치하면 편해요.

### 6. 부부가 같이 쓰기
1. 배포된 주소를 두 폰에서 열기 → 비밀번호 4자리 입력
2. **아내/남편** 중 내 역할 선택
3. 처음 들어온 사람은 **처음 설정**에서 아기 이름과 출산(예정)일 저장 (배우자 화면에도 똑같이 보여요)
4. 브라우저 메뉴에서 **홈 화면에 추가**

## 문제 해결
- **"비밀번호가 맞지 않아요"**: 2단계에서 비밀번호를 `pin-숫자4자리`로 만들었는지, 이메일이 config.js의 `LOGIN_EMAIL`과 같은지 확인하세요.
- **"권한 오류"가 떠요**: 3단계 규칙을 붙여넣고 **게시**했는지, 규칙의 이메일이 `LOGIN_EMAIL`과 같은지 확인하세요.
- **"연결하지 못했어요"**: `config.js` 값에 오타가 없는지 확인하세요.
- **기본 리스트가 비어 있어요**: 인터넷에 연결된 상태에서 한 번 열어야 처음 리스트가 만들어져요.

## 보안·개인정보 참고
- 숫자 4자리 비밀번호는 경우의 수가 1만 개라, 주소를 아는 사람이 계속 시도하면 뚫릴 수 있어요. Firebase가 반복 시도를 어느 정도 막아줘요. 주소와 비밀번호는 배우자에게만 알려주세요.
- 신분증·계좌·카드 번호 같은 민감한 정보는 메모에 적지 마세요.
- 무료 사용량(Spark 요금제) 안에서 충분히 돌아가는 규모예요.

## 정책 정보 안내
출산 후 신청 항목의 금액·기한은 2026년 기준 공개 자료를 조사한 내용이에요. 지자체별로 다른 항목이 있고 해마다 바뀌므로, 신청 전에 복지로·정부24·고용24 등 공식 사이트에서 최신 내용을 확인하세요.
